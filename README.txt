FITPROGRESS WEB APP v3

Novità rispetto alla v2:
- timer di recupero compatto e non bloccante, così puoi consultare gli esercizi;
- avviso sonoro e vibrazione al termine del recupero (la vibrazione dipende dal dispositivo/browser);
- per il plank si inseriscono i secondi invece delle ripetizioni;
- diario manuale giornaliero per passi, calorie attive, calorie assunte, proteine, carboidrati, grassi e peso;
- medie degli ultimi 7 giorni per i dati inseriti;
- i dati vengono salvati localmente nel browser e l'esportazione JSON include anche il diario giornaliero.

Nota: il timer sonoro può richiedere che Safari sia stato prima toccato/interagito con. I dati restano sul dispositivo/browser: esporta periodicamente un backup da Altro.
